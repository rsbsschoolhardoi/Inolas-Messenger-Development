# Zenoa Bot Dispatch Skill

Configure bots and event handlers on the Zenoa network.

## Bot Setup
1. Generate Bot Token in the Zenoa Developer Console (`https://zenoa.in/developer`).
2. Subscribe to incoming message webhooks at `/api/v1/webhooks/subscribe`.
3. Respond to incoming chat commands via `/api/v1/bot/reply`.

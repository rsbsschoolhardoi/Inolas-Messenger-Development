# UI/UX Pro Max Skill — Persistent Directives

This project follows the **UI/UX Pro Max Skill** standard:
- **Design Intelligence**: High-contrast, mathematically spaced (8pt grid), optically balanced user interfaces.
- **Anti-Slop**: No generic gradients, no card-in-card nesting, no wrapped pill labels.
- **Typography**: Step ratio $\ge 1.25$, line heights 1.5–1.7, 65–75ch readability constraints.
- **Accessibility**: WCAG AA $\ge 4.5:1$ body contrast, 44px touch targets, full keyboard and ARIA navigation support.
- **Motion**: 150-250ms subtle easing curves for interactive elements.
- **21st.dev Components**: Configured via MCP (`https://21st.dev/api/mcp`) for high-craft UI component patterns.
